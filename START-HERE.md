# O‘zbekistonga maktub

Saytni mahalliy ishga tushirish uchun Node.js 20+ bilan:

```bash
npm run dev
npm test
```

`http://localhost:3000` va `/gallery/` manzillari mavjud. Kod `arena/3fdaad18-brag` branchida. `brags` Vercel loyihasi repoga ulangan; yangi o‘zgarishlarni chiqarish uchun kerakli commitni deploy qiling.

Arxivdagi `push-to-github.sh` tarixiy yordamchi skript bo‘lib, default branchga yuboradi; bu sessiyada undan foydalanilmaydi. Rasmlar manbalari `assets/credits.json`, shrift litsenziyalari `docs/licenses/` ichida.
